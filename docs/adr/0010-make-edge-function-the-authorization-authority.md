# Make the Edge Function the authorization authority

The You Pick Edge Function is the authorization authority: it verifies anonymous participant JWTs, derives participant IDs only from verified tokens, and explicitly checks ownership before mutations. Because one function contains public reads and protected writes, platform `verify_jwt` is disabled and shared route middleware performs mandatory JWT verification for every mutation; missing or invalid identity returns `401`, while inaccessible suggestions return `404`. Its server-only Supabase secret bypasses RLS so browsers can be denied direct table access; database constraints instead provide the second safety layer for uniqueness, valid values, and length limits, with two-participant integration tests proving ownership isolation.
