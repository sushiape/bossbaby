# BossBaby Website

Public brand and community site for Bossbaby, plus the entry point to the
unreleased Bossbaby application. React/Vite frontend on Vercel; Supabase
migrations and Edge Functions under `backend/supabase/`.

## Agent skills

### Issue tracker

GitHub Issues on `sushiape/bossbaby` via the `gh` CLI. Product and roadmap work
is tracked separately in Jira project BBDEV. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels, used unchanged. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See
`docs/agents/domain.md`.
